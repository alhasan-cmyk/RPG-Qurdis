LEMBAH ILMU — siap diunggah ke GitHub Pages
============================================

CARA TERCEPAT (tanpa terminal)

1. Buat repository baru di github.com, misalnya bernama "lembah-ilmu".
   Pilih Public (Pages gratis hanya untuk repo publik di akun gratis).

2. Unggah SEMUA berkas di dalam zip ini ke repo itu:
   - lewat web: tombol "Add file" -> "Upload files", lalu seret seluruh isi
     folder (bukan foldernya, tetapi berkas dan subfoldernya),
   - atau lewat terminal (lihat bagian bawah).

   Yang penting: index.html harus berada di AKAR repo, bukan di dalam
   subfolder. Begitu juga game.html dan folder src/ serta assets/.

3. Buka Settings -> Pages. Di bagian "Build and deployment":
     Source   : Deploy from a branch
     Branch   : main  /  (root)
   Simpan. Tunggu 1-2 menit.

4. Alamat situsmu:
     https://NAMA-AKUN.github.io/lembah-ilmu/

   BAGIKAN ALAMAT INI SAJA ke murid. Halaman itu yang punya formulir
   "Mulai Petualangan" (username + PIN). Tombol MULAI BARU membawa murid ke
   permainan setelah akunnya tercatat.

   JANGAN membagikan /game.html. Alamat itu memang masih bisa dibuka, tetapi
   sekarang memulangkan murid tanpa akun ke halaman pendaftaran, jadi tidak ada
   lagi yang bermain sebagai "Petani" tanpa nama — dan nilai ujiannya tidak
   hilang karena akunnya tidak ada.

TAMPILAN DI PONSEL — SELALU MENDATAR
=====================================
Game ini butuh layar lebar. Di ponsel yang masih tegak, layarnya otomatis
disiapkan mendatar: kanvas diputar 90 derajat dan muncul ajakan "Putar ponselmu
mendatar". Murid tinggal memiringkan ponselnya (atau menekan tombol
"Putar otomatis" di Android) dan seluruh layar terpakai — hotbar, panel, dan
petunjuknya jadi kelihatan semua.

Murid yang membuka dari komputer tidak terpengaruh. Kalau jendela perambannya
sempit dan tinggi, muncul ajakan memperlebarkan jendela, bukan memutar gambar.

LAYAR LEBIH LEGA
================
Tombol bulat di pojok kanan atas layar permainan:

  ⛶  Layar penuh. Bilah alamat dan tombol peramban hilang, jadi layarnya
     bertambah tinggi. Di Android ini juga membuat kunci mendatar lebih andal.
     Menekannya sekali lagi mengembalikan seperti semula.
     (Peramban melarang layar penuh tanpa ketukan, jadi memang harus ditekan —
     tidak bisa muncul sendiri.)

Di iPhone/iPad tidak ada tombol itu, karena Safari di sana memang tidak punya
layar penuh. Gantinya: buka lewat Safari, ketuk Bagikan, lalu "Tambahkan ke
Layar Utama". Game akan terbuka tanpa bilah alamat, seperti aplikasi.

LUAS PANDANGAN (Pengaturan)
===========================
Esc -> Pengaturan -> "Luas pandangan" (ubah dengan panah kiri/kanan):

  Normal       gambar dunia 1:1, paling tajam, cocok untuk komputer.
  Luas (bawaan di ponsel)
               pandangan +43%, jadi semua tombol dan panel pasti masuk layar.
  Sangat luas  pandangan 2x, untuk layar yang sangat sempit. Piksel tetap
               tajam karena 1 piksel dunia = tepat 0,5 piksel layar.

Yang diperkecil HANYA gambar dunianya. HUD, hotbar, teks, dan panel tetap
sebesar biasa — itu sebabnya tulisan tidak ikut mengecil dan tidak ada yang
terpotong. Di ponsel "Luas" dipilih otomatis saat pertama dibuka.

CARA LEWAT TERMINAL

   git init
   git add .
   git commit -m "Lembah Ilmu"
   git branch -M main
   git remote add origin https://github.com/NAMA-AKUN/lembah-ilmu.git
   git push -u origin main

   Lalu lakukan langkah 3 di atas sekali saja.

CARA OTOMATIS (repo berisi KODE SUMBER, bukan isi situs)

Pakai cara ini kalau yang kamu unggah adalah zip "lembah-ilmu-game-sumber.zip"
(proyek lengkap). Di dalam zip itu sudah ada:
  .github/workflows/pages.yml  — penyusun + penerbit otomatis
  tools/publish.py             — menyusun dist/ dari src/ dan assets/

Setelah repo berisi kode sumber dan didorong ke GitHub:
  1. Settings -> Pages -> Source: GitHub Actions
  2. Setiap dorongan ke `main`, GitHub menjalankan tools/publish.py lalu
     menerbitkan hasilnya. Riwayat build ada di tab Actions.
  3. Alamatnya tetap https://NAMA-AKUN.github.io/lembah-ilmu/ dan
     /game.html.

Jangan pakai dua cara sekaligus (branch dan Actions); pilih salah satu.
Kalau repo berisi ISI SITUS (zip ini), pakai cara branch di atas.

YANG PERLU DIKETAHUI

- Akun murid dicatat LANGSUNG dari peramban ke Web App Apps Script (tab `Akun`
  di spreadsheet guru); nilai juga langsung ke Apps Script (tab `Nilai`).
  Tidak ada server perantara, jadi tidak ada yang perlu dinyalakan.
- Keluar dari permainan: klik/tap tombol POWER (lingkaran merah) di kiri atas,
  tepat di kiri panel gold, lalu pilih "Keluar ke menu utama". Tombol ini SATU
  untuk semua perangkat (laptop, HP, tablet) dan selalu terlihat; Esc tetap
  bekerja sebagai jalan pintas. Bisa juga dimatikan lewat Pengaturan > "Tombol
  power".
- Tombol power digeser dengan `translateY(-50%)` supaya titik tumpunya adalah
  GARIS TENGAH panel gold. Tanpa itu tombolnya selalu duduk 20 px di bawah
  angka gold — persis keluhan "power belum dinaikkan" yang muncul berulang.
- Tata letak tombol layar: power dan inventori (I) SEBARIS dengan angka gold
  (digantung pada garis tengah IKON koin, bukan garis tengah kotak panel — kalau
  memakai tengah kotak, tombolnya terlihat melorot 4 px); D-pad (empat tombol
  arah) dirapatkan 2 px antar tombol supaya terbaca sebagai satu pad, dan
  diletakkan di kiri bawah,
  kluster kanan di kanan bawah — keduanya didorong turun sampai hampir
  menyentuh dasar layar, tetapi kalau hotbar angka kebetulan sampai ke
  sudutnya, tombolnya dinaikkan kembali ke atas hotbar supaya slot tidak
  tertutup. Tombolnya juga dibuat lebih tembus pandang (isi ~58%, E ~68%)
  supaya dunia di belakangnya masih kelihatan. Deretan ini hanya tampil kalau
  "Tombol sentuh" di Pengaturan hidup; tombol power tetap ada meski deretan itu
  dimatikan. Progres disimpan
  OTOMATIS tepat sebelum pertanyaan konfirmasi muncul, jadi membatalkan
  pertanyaannya tidak membatalkan simpanan. Ada juga baris "Simpan sekarang"
  di menu yang sama untuk yang ingin memastikan.
- PAPAN RAGAM USAHA (papan di samping pintu rumah) menjual DUA jenis barang di
  satu layar, dan keduanya penting:
    1. PENINGKATAN BANGUNAN — rumah, lemari, peti, dapur, pasar, kandang, kebun
       bibit. Dibayar dengan uang + bahan hasil ladang, dan masing-masing
       dikunci satu bab: bab itu harus lulus dulu. Efeknya besar dan terasa tiap
       hari, jadi jangan diabaikan. Harga di bawah adalah tingkat pertama;
       tingkat berikutnya menagih kelipatannya (tingkat 2 = dua kali):
         · Rumah        G1.200 · 25 batu · 30 kayu            (1 tingkat)
                        energi maksimum +20 (dasar 100)
         · Lemari       G400  · 20 kayu · 10 serat            (4 tingkat)
                        slot tas +4 (dasar 24)
         · Peti         G600  · 25 kayu · 10 batu             (3 tingkat)
                        slot peti +8 (dasar 24)
         · Dapur        G900  · 20 batu · 15 kayu · 4 telur   (1 tingkat)
                        makanan memulihkan +25% energi
         · Pasar        G800  · 10 lobak · 8 kentang · 8 tomat (3 tingkat)
                        harga jual hasil ladang +10%
         · Kandang      G1.400 · 40 kayu · 10 batu · 10 serat (1 tingkat)
                        menambah ternak (sampai tiga)
         · Kebun bibit  G500  · 12 kayu · 20 serat            (3 tingkat)
                        membagi benih gratis tiap pagi
       Papan menulis nomor bab dan nama gurunya di kolom kanan; kalau babnya
       belum lulus, yang harus dicari adalah GURUNYA, bukan papan lainnya.
       Satu bab hanya membuka SATU peningkatan, jadi tidak ada bab yang
       ditagih dua kali. Tiap kelas (X, XI, XII) punya bab syarat sendiri.
    2. BENGKEL KENDARAAN — bawah daftar yang sama, dibeli dengan diamond.
  Tekan E pada baris untuk membeli. Baris yang sudah maksimum ditandai
  "penuh".
- KENDARAAN (bagian bawah papan yang sama): tiga kendaraan dibeli dengan
  diamond — Sepeda 10, Sepeda motor 25, Truk pengangkut barang 50.
  Tidak ada syarat bab dan tidak ada bahan; diamond satu-satunya mata uangnya.
  Gunanya berbeda, bukan cuma "lebih cepat":
    · Sepeda        2x lebih cepat dari jalan kaki
    · Sepeda motor  3,5x lebih cepat (paling gesit)
    · Truk          tas +12 slot (hasil panen tidak perlu bolak-balik) dan
                    1,8x lebih cepat
  Yang dibeli langsung dipakai. Tekan E pada kendaraan yang sedang dipakai
  untuk turun dan kembali jalan kaki — hanya SATU yang bisa dipakai sekaligus,
  jadi sepeda tetap berguna setelah punya truk.
  WUJUDNYA IKUT BERUBAH: pemain yang memakai kendaraan benar-benar duduk di
  atasnya (sepeda, motor, atau truk) di dunia, bukan cuma bergerak lebih cepat
  sambil tetap berjalan kaki. Tinggi kepalanya sama seperti saat berjalan, jadi
  tidak ada "loncatan" saat naik atau turun. Keempat avatar (laki-laki,
  perempuan, dan dua varian lainnya) punya lembarnya sendiri.
  Bingkai sprite kendaraan lebih besar dari pejalan kaki (sepeda & motor 48x64,
  truk 64x64) supaya roda, rangka, dan kabin truk benar-benar muat — tetapi yang
  membesar hanya kendaraannya: kepala pemain tetap di ketinggian yang sama.
  Karena itu:
    · sepeda  dua roda besar (13 px) dengan rangka, sadel, setang, keranjang
    · motor   bentuk skuter: dek pijak, perisai kaki, jok, lampu, spion
    · truk    kabin besar berjendela; dari samping kepala & bahu pengemudi
              terlihat di dalam kabin, dari depan lewat kaca depan
    · truk dari BELAKANG hanya memperlihatkan baknya, tanpa pengendara
  Lembar sprite dibuat ulang dengan `node tools/buat-sprite-kendaraan.mjs`;
  kalau skrip itu diubah tanpa membuat ulang, tests/uji.mjs akan gagal
  ("berkas berbeda").
- USTADZ TASORO — guru mengaji keliling, berpeci dan naik sepeda motor.
  Ia TIDAK tinggal di satu tempat: ia memutari lembah lewat jalan desa, lalu
  BERHENTI 8–15 detik di Balai Desa dan Perpustakaan, dan hanya saat berhenti
  itu ia bisa diajak bicara. Kalau ia sedang melaju, label "Bicara" tidak
  muncul — tunggu di salah satu dari dua tempat tadi, jangan dikejar.
  Motornya tidak pernah dimatikan saat berhenti: ia tetap digambar di atas
  motornya, bukan berdiri di sampingnya.
  Yang ia berikan BUKAN ujian bab, melainkan dua jalur tambahan atas LIMA BAB
  PERTAMA kelasmu:
    · REMEDIAL  — 50 soal (10 untuk tiap bab dari lima bab pertama) untuk
                  mengulang pelajaran yang belum dikuasai. Boleh ditempuh kapan
                  saja, tanpa syarat sudah lulus bab mana pun — justru untuk
                  murid yang BELUM lulus.
    · PENGAYAAN — 50 soal dari lima bab yang sama, tetapi menuntut nalar
                  (menganalisis, membandingkan, menilai), bukan hafalan.
  Keduanya 50 soal per kelas (X, XI, XII punya bank sendiri), dan soalnya
  DIUNDI dari bank itu setiap kali, jadi mengulang tidak menghafal urutan.
  Nilai lulusnya sama: 80% (40 benar dari 50).
  HASILNYA MASUK SPREADSHEET GURU, tetapi di tempat yang berbeda:
  ujian bab menulis ke tab `Nilai`, sedangkan remedial & pengayaan menulis ke
  tab `Remedial`. Jadi keduanya tercatat untuk guru tanpa pernah tercampur
  menjadi "nilai sekolah".
  Yang dikirim ke tab `Remedial`:
    · SEMUA hasil, lulus maupun belum — justru yang belum lulus yang perlu
      diketahui guru sebelum remedial ulang (beda dengan ujian bab, yang hanya
      mencatat nilai 80% ke atas);
    · rincian benar/salah per bab, mis. "x-wahyu 9/10 · x-nuzul 6/10".
  Layar hasil menyebut benar/salah PER BAB, supaya jelas bab mana yang harus
  dibaca ulang, dan menyebut terus terang apakah hasilnya sudah terkirim,
  masih ditahan karena jaringan, atau gagal.
  PENTING — apa yang TIDAK dilakukan kedua jalur ini:
    · tidak menulis "lulus" untuk bab mana pun, jadi tidak membuka peningkatan
      di papan Ragam Usaha dan tidak membuka alat;
    · tidak masuk nilai sekolah: angkanya tidak pernah ditulis di tab `Nilai`
      dan tidak mengubah nilai bab mana pun;
    · hanya PENGAYAAN yang lulus yang memberi +1 diamond (remedial tidak,
      karena remedial adalah latihan ulang, bukan prestasi baru).
- DIAMOND: setiap ujian bab yang LULUS memberi +1 diamond, dan mengulang bab
  yang sama juga +1 lagi (tanpa batas). Tidak lulus = 0. Hadiahnya per ujian,
  bukan per soal — satu bab yang banknya 30 soal tetap 1 diamond. Angkanya
  tampil di baris atas panel kanan (di atas gold) dan langsung disimpan begitu
  didapat, jadi tidak hilang walau halaman ditutup sebelum sempat tidur.
  Diamond dibelanjakan di bagian bawah papan Ragam Usaha — untuk kendaraan
  (lihat di atas).
- Slot tas = 24 + tingkat lemari (4 tiap tingkat) + tambahan truk (12 kalau truk
  sedang dipakai). Dihitung ulang setiap kali papan dibeli atau kendaraan
  berganti, jadi tas tidak "menyusut" saat turun dari truk.
- Simpanan permainan hanya tersimpan di peramban masing-masing (localStorage).
  Membuka game dari komputer lain akan mulai dari awal, tetapi akun dan nilai
  tetap dianggap sah karena PIN diperiksa Apps Script.
- Obrolan desa TIDAK ADA di GitHub Pages: `api/chat` butuh server Python
  (`tools/serve.py`). Di GitHub Pages fitur obrolan mati, dan itu tidak
  memengaruhi pendaftaran, permainan, ujian, maupun nilai.
- Kalau ingin obrolan hidup, jalankan `python3 tools/serve.py` di komputer
  atau VPS. Lihat JALANKAN.md bagian 7.
- Nilai murid masuk ke spreadsheet guru; sambungannya diatur di
  src/core/nilai-api.js. Isi spreadsheet ada di EMPAT tab:
    `Akun`      nama, kelas, PIN (hash) — diisi otomatis saat mendaftar
    `Nilai`     satu baris per ujian BAB yang LULUS
    `Remedial`  satu baris per percobaan REMEDIAL/PENGAYAAN (lulus atau tidak)
    `Rekap Nilai`  SATU BARIS PER MURID, nilai berjejer ke samping
  Tab `Rekap Nilai` itulah yang dipakai guru melihat sekilas: nama di kiri,
  lalu kolom per bab (Bab I, Bab II, ...), ditutup kolom Remedial dan
  Pengayaan. Contohnya satu baris berbunyi: ahmad · 90 · 90 · 90 · 87 · 62 · 88.
  Yang ditampilkan adalah nilai TERBAIK tiap bab (bukan percobaan terakhir),
  sel hijau = tuntas (>= 80), sel oranye = belum. Rekap disegarkan otomatis
  setiap kali ada nilai masuk, dan bisa disegarkan manual lewat menu
  "Lembah Ilmu -> Segarkan Rekap" di spreadsheet, atau dengan membuka
  URL /exec?aksi=rekap di peramban.
- Kalau kode server spreadsheet (Apps Script) diubah, JANGAN lupa
  Deploy -> Manage deployments -> Edit -> Version: New version. Tanpa langkah
  itu URL /exec masih menjalankan kode lama, dan nilai murid akan gagal
  terkirim walau berkas Code.gs sudah benar.

KODE DEBUG (HANYA UNTUK MENGUJI)

Untuk pengetes dan guru, supaya tidak perlu mengumpulkan gold dan diamond
dengan bermain dulu. TIDAK AKTIF pada pemakaian biasa: harus dibuka dengan
menambahkan ?debug=1 di alamat halaman, misalnya

  game.html?debug=1

Di GitHub Pages: .../RPG-Qurdis/game.html?debug=1 . Penandanya juga disimpan
selama TAB itu hidup, jadi ?debug=1 yang diketik di halaman depan ikut terbawa
saat menekan "Main", tetapi hilang begitu tab ditutup (peramban sekolah dipakai
bergantian dan murid berikutnya tidak boleh mewarisi mode debug). Tanpa
penanda itu tidak ada satu pun perintah di bawah yang bekerja.

CARA MEMBUKANYA: tekan F2, atau tekan / (garis miring). Sebuah baris perintah
muncul di bawah layar; ketik perintahnya lalu Enter. Garis miring di depan
diketik otomatis, jadi cukup `gold 1000`. Esc membatalkan. Panah atas mengulang
perintah sebelumnya. F1 menampilkan/menyembunyikan daftar perintah di layar.

  /gold 1000      gold +1.000 (tanpa angka = +1.000; angka negatif boleh,
                  mis. /gold -500 untuk menguji keadaan miskin)
  /diamond 1000   diamond +1.000 (tanpa angka = +1.000)
  /bahan 50       bahan +50 tiap jenis: batu, kayu, serat, telur, lobak,
                  kentang, tomat, susu (tanpa angka = +50)
  /bab 1          bab berikutnya yang belum lulus dianggap lulus (boleh
                  /bab 3 untuk tiga bab sekaligus)
  /babsemua       semua bab kelas yang sedang dipakai dianggap lulus
  /tingkat 1      semua peningkatan bangunan naik 1 tingkat, tanpa bahan dan
                  tanpa uang; efeknya langsung berlaku (energi maks, slot tas,
                  slot peti, ternak) karena pembeliannya lewat jalur yang sama
                  dengan papan (/tingkat 3 untuk tiga tingkat)
  /energi         energi penuh
  /kendaraan      sepeda, motor, dan truk diberikan tanpa memakai diamond
  /jam 1          waktu maju 1 jam (jadwal warga dan lampu malam ikut jalan)
  /musim          ganti musim
  /simpan         simpan sekarang, tanpa menunggu tidur

KENAPA PERINTAH KETIK, BUKAN Ctrl+D / Ctrl+G

Versi pertama memakai Ctrl+G (gold) dan Ctrl+D (diamond). Itu TIDAK bisa
diandalkan: Ctrl+D adalah "tandai halaman" dan Ctrl+G adalah "cari berikutnya"
di Chrome, dan peramban boleh memprosesnya sebelum halaman sempat mencegah.
Hasilnya cheat terasa "tidak jalan" padahal kodenya benar. Perintah ketik tidak
bergantung pada peramban, bisa dibaca ulang sebelum dijalankan (tidak ada
gold yang masuk karena salah tekan), dan bisa diberi angka.

Alias Ctrl+G / Ctrl+D / Ctrl+B / Ctrl+K / Ctrl+L / Ctrl+J / Ctrl+H / Ctrl+M /
Ctrl+U / Ctrl+P / Ctrl+Y masih terpasang bila kebetulan berhasil, tetapi
BUKAN jalan yang diandalkan — pakai perintah ketik. Ctrl+R, W, T, N, Q tetap
milik peramban (muat ulang, tutup tab, buka tab, jendela baru, keluar).

YANG PERLU DIKETAHUI SAAT MENGUJI

- Cheat TIDAK menulis keadaan secara langsung. /tingkat memakai bahan yang
  diberikan cheat lalu membelinya seperti pemain menekan E di papan; /kendaraan
  memakai jalur pembelian kendaraan; /diamond memakai penambah diamond yang sama
  dengan hadiah ujian. Jadi keadaan yang dihasilkan selalu keadaan yang bisa
  dicapai dengan bermain, dan bug yang sedang dicari tetap muncul.
- /bahan melaporkan berapa bahan yang TIDAK muat kalau tas penuh; kalau semuanya
  muat, pesannya menyebut jumlah yang masuk.
- Salah ketik nama perintah tidak menutup baris; pesannya menyebut daftar
  perintah yang ada, jadi bisa langsung diperbaiki.
- Baris perintah tidak merampas tombol saat kursor ada di kotak obrolan.
- Kode debug ada di src/core/cheat.js (perintah) dan src/ui/cheat-console.js
  (baris perintah), dan hanya dipasang di dalam blok mode debug di src/main.js.
  tests/uji.mjs memeriksa dua arah: harus terpasang di dalam blok itu, dan tidak
  boleh ada pemanggilan di luarnya.

MEMERIKSA DATA SEBELUM MENDORONG

Alat-alat ini tidak memerlukan peramban. Semuanya cukup Node.js saja, kecuali
yang terakhir: ia butuh DOM (`npm i jsdom`) dan akan melewati dirinya sendiri
kalau jsdom belum terpasang.

  node tools/buat-sprite-kendaraan.mjs  # membuat ulang 12 lembar sprite
                                     # "pemain menaiki kendaraan" (butuh Node
                                     # saja, tanpa pustaka tambahan)
  node tools/buat-sprite-tasoro.mjs  # membuat ulang sprite & potret Ustadz
                                     # Tasoro (lembar jalan kaki 32x48, lembar
                                     # motor 48x64, potret 96x96)
  node tools/periksa-data.mjs        # 30 bab, 900 soal, 300 soal remedial &
                                     # pengayaan, pembagian bab ke warga, alat,
                                     # dan isi papan Ragam Usaha
  node tools/uji-tata-letak.mjs      # layar Ragam Usaha di lima ukuran layar:
                                     # nama guru utuh, kalimat tidak terpotong
  node tools/uji-tasoro.mjs          # layar ujian & hasil remedial/pengayaan di
                                     # lima ukuran layar: 50 soal tertulis,
                                     # rincian lima bab tampil, janji "tidak masuk
                                     # nilai sekolah" tidak hilang
  node tools/uji-rekap.mjs           # server spreadsheet (apps-script/Code.gs)
                                     # diuji tanpa Google: nilai di bawah 80
                                     # ditolak untuk ujian bab, DITERIMA untuk
                                     # remedial, dan tab Rekap berisi satu baris
                                     # per murid dengan nilai berjejer
  node tests/uji.mjs                 # seluruh uji sistem (±3.300 pemeriksaan)
  node tools/uji-sentuh.mjs          # baris "Tombol sentuh" di Pengaturan
                                     # (butuh DOM: npm i jsdom)

Jalankan semuanya sebelum mendorong. Yang paling perlu dijaga adalah setiap kali
mengubah src/data/ilmu.json atau src/systems/upgrade.js: kesalahan di dua berkas
itu tidak membuat game error — ia hanya membuat keterangan di layar menjadi
salah, misalnya satu bab ditagih dua kali atau nama guru tidak muncul. Itu
paling sulit ditemukan saat bermain, jadi diperiksa di sini.
